# 终末地 · 祀岁翼（EndfieldWings）

适配 tModLoader 1.4.4 的翅膀饰品 mod，主题为《明日方舟：终末地》风格的「祀」。

## 功能

### 祀岁翼

- 无限飞行
- 巡航 / 悬浮两种模式，空中双击跳跃切换
- 巡航：长按跳跃持续加速上升，跳跃 + ↓ 悬停
- 悬浮：松手即停、即时变向、按住 ↑/↓ 匀速升降
- 中文名「祀岁翼」，悬停时名字颜色循环流动
- 最高稀有度

### 十二刻印

子武剑、丑谋棋、寅诗壶、卯律钟、辰文书、巳农桩、午商梭、未建尺、申铸轮、酉疗秤、戌绘卷、亥食灶，各自带独立被动。

### 十三权能

装备祀岁翼后，按 **O** 打开权能轮盘，点击印记开关对应权能：

- 开乾：最终伤害提升，攻击概率无视防御
- 势坤：最终伤害减免，概率闪避
- 逍遥：免疫负面效果
- 色空：只有中心极小范围会被弹幕命中
- 意义：致命伤免疫并回满生命
- 因果：命中叠加层数，叠满后范围爆发并回血
- 虚实：免疫接触、陷阱与环境伤害
- 相合：造成的伤害额外视为近战 / 远程 / 魔法 / 召唤伤害
- 形：解锁全部配方环境
- 死：附加最大生命
- 生：持续回复最大生命
- 夕（意）：开启画卷空间
- 轮盘中心：演化开关

### 合并 HUD

- 右上角小地图左侧，显示权能与岁时状态
- 左键图标打开权能轮盘
- 右键拖动，位置随角色存档保存
- 模组设置可隐藏 HUD、关闭拖动

### 画卷空间

- 装备戌绘卷或开启「意」后，按 **U** 打开
- 50 格随身储物，点击与鼠标物品互换
- 开启「意」时每天天亮存量翻倍；武器、饰品每次放入额外复制一次
- 物品存在角色存档，摘下戌绘卷不会丢失

### 主界面主题

- 主菜单可选「祀岁翼 · 花祀时」：整屏背景图 + 主题曲
- 隐藏 tModLoader logo
