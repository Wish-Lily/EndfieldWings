# 05 · 获取与进度

## 一、目标

最终饰品，强度不设上限；能力靠**解锁**获得。两条路线并行：

- **Boss 战斗**：击败「岁时」Boss 才具备合成资格
- **12 件合成**：12 枚兄姐刻印 + 祀岁翼 → 全部权能完整版
- **使用成长**：岁·演化随使用自动成长

## 二、获取图

```
击败「岁时」Boss（阶段：岁兽残识 → 岁醒天时）
   │ 掉落：岁时材料 / 合成资格
   ▼
祀岁翼（最终饰品，13 权能整合）
   │
   ├─ 12 枚「兄姐刻印」（饰品）
   │     单独佩戴 = 该权能的弱化版（尚未设计）
   │     集齐后与祀岁翼合成 → 权能升级为完整版
   │
   ├─ 岁·演化：使用祀岁翼累计（飞行距离 + 击杀）
   │
   └─ 「岁醒天时」→ 12 时辰轮盘与刻文
```

> 「祀岁翼」本身是**打过 Boss 之后合成**的，不是 Boss 直接掉落。

## 四、合成与祭坛

- 建议新增一个「墨绘祭坛」（可放置在任意位置，或使用原版祭坛替代）
- 合成表：
  - 祀岁翼 + 12 枚刻印 → 十三权能之翼
  - 岁醒天时作为可选材料，不强制（没有它也能用飞行，只是没有时辰被动）

## 五、强度基准

- 移动：天界星盘级别
- 12 权能全开：约等于「星盘 + 3~4 件终局饰品」
- 主动技冷却 3~25 秒，终极技 3 分钟
- 不做资源消耗与失败概率
