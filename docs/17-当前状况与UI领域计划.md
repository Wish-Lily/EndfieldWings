## 三、领域设计

### 两种档次

| | 岁兽残识 | 岁醒天时 |
|---|---|---|
| 半径 | 22 格 | 40 格 |
| 同时时辰 | 1 | 2（当前 + 残留） |
| 轮换 | 18 秒 | 12 秒 |
| 强度 | 单一弱化 | 主效果 + 追加效果 |
| 离开 | 3 秒后消失 | 立即消失，2 秒内回来续上 |

12 时辰的具体负面效果见 `docs/11-岁时领域负面效果草案.md`。

### 实现骨架

```
Common/Shichen/Domain/
  ShichenDomainSystem.cs   ModSystem：Boss 战状态、当前时辰、半径、轮换计时、网络同步
  ShichenDomainPlayer.cs   ModPlayer：进出领域检测、施加/移除 debuff
  ShichenDomainVisuals.cs  领域圆环、墨色渐变、时辰字
  ShichenDebuff.cs         12 个 ModBuff（或 1 个带类型的 Buff + 图标切换）
Boss/
  SuiBossAI.cs             阶段控制：残识 → 天时
```

### 关键设计点

1. **进出检测**：每帧算玩家到 Boss 的距离，进入/离开时增删 buff，不要每帧重复添加
2. **领域视觉效果**：`ModSceneEffect` 或 `ModSystem.PostDrawTiles` 画圆环；时辰字用 `Main.fontMouseText`
3. **多人**：只同步「Boss 阶段 + 当前时辰 + 半径」，玩家侧各自算
4. **可解**：离开领域 3 秒解除；「逍遥」可免疫（完整版）
5. **HUD**：领域激活时显示剩余时间和当前时辰

## 四、建议顺序

1. **岁时轮盘 HUD**（小、独立，先做能马上看到）
2. **领域骨架**：半径 + 时辰轮换 + 1 个时辰效果（子武）验证

4. **Boss 阶段控制**（残识 / 天时）
