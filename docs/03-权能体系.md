## 五、实现注意

- 「最终伤害」类效果用 `NPC.HitModifiers.FinalDamage` / `Player.HurtModifiers.FinalDamage`，不要直接乘 `GetDamage`（那只是武器面板）。
- 免死、闪避都走 `FreeDodge` / `PreKill`，避免和原版无敌帧打架。
- 延迟结算的伤害要处理玩家死亡、退出世界、切角色。
- 「相合」同时吃四类加成容易数值爆炸，实现时先定一个口径（相加 or 取最高）。
- 「虚实」要在 `ModifyHurt` 里按来源分类：接触（NPC 碰撞）、环境（岩浆/溺水/摔落/窒息）、爆炸（爆炸类弹幕与物品）；分类表要单独维护。
- 「演化」的「代码杀」指不经伤害结算、直接置死的效果（`KillMe` / 直接设 `statLife = 0` / 超大固定伤害）；实现时拦 `PreKill`，改成一次 `player.Hurt(最大生命值)`，让护甲/减伤/免伤/免死正常参与。
- 碰撞箱减小会影响物块碰撞、坐骑、床，需实测。
- 「意」的探索度没有现成 API，可能要用 `Main.Map` 的探索位图或自建统计。
