# 07 · 开发环境与约定

## 一、环境

| 项 | 值 |
|---|---|
| 游戏 | Terraria 1.4.4 内容线 |
| tModLoader | **1.4.4.9**，装在 `F:\SteamLibrary\steamapps\common\tModLoader` |
| .NET | 8.0 SDK（`C:\Program Files\dotnet`） |
| 工程目录 | `E:\Code\deepseek\TerrariaMod\EndfieldWings` |
| 模组内部名 | `EndfieldWings` |

## 二、构建

游戏内：**Workshop → Develop Mods → Build + Reload**

命令行验证（无需开游戏）：

```powershell
cd 'F:\SteamLibrary\steamapps\common\tModLoader'
dotnet .\tModLoader.dll -build 'E:\Code\deepseek\TerrariaMod\EndfieldWings'
```

成功输出：

```
Compiling EndfieldWings.dll
Compilation finished with 0 errors and 0 warnings
Packaging: EndfieldWings
```

> 构建时出现 `WARN: Image loading failed` 通常是 `icon_small.png` 引起的已知现象
> （官方 ExampleMod 同样会报），不影响游戏内加载。

## 三、PNG 的坑（重要）

- **Pillow 直接保存的 PNG，tML 的图片加载器可能读不出来**（图标会加载失败）。
- 生成/编辑完 PNG 后，用 GDI+ 重编码一遍：

```powershell
Add-Type -AssemblyName System.Drawing
$img = [System.Drawing.Bitmap]::FromFile($png)
$img.Save("$png.tmp.png", [System.Drawing.Imaging.ImageFormat]::Png)
$img.Dispose()
Move-Item "$png.tmp.png" $png -Force
```

## 四、命名与目录约定

- 物品/贴图：文件名 = 类名，PNG 与 `.cs` 同目录。
- 翅膀装备贴图：`<ItemName>_Wings.png`，由 `[AutoloadEquip(EquipType.Wings)]` 自动加载。
- 本地化：`Localization/zh-Hans_Mods.EndfieldWings.hjson`（英文对应 `en-US_...`）。
- 新代码按功能分目录：
  - `Common/Players/`：`ModPlayer`
  - `Common/Authorities/`：权能
  - `Common/Shichen/`：时辰
  - `Content/Items/Accessories/`：饰品

## 五、版本备份约定

- 每次大改贴图，先把当前 `SiWings_Wings.png` 复制到 `TerrariaMod/versions/`，
  命名 `SiWings_Wings_vN_日期.png`，再覆盖。
- 现有：v1（描摹设定图）、v2_thin（纯实装羽翼）、v3_hybrid（混合版），当前 v4。
- 回滚：把备份覆盖回 `Content/Items/Accessories/SiWings_Wings.png` 即可，不用改代码。

## 六、临时文件

- 分析/生成用的临时脚本、视频帧等，用完即删；不要留在项目里。
- 参考图（`祀翅膀.png`、`祀翅膀设定图.png`）在**工作区根目录**，属于用户素材，不要删。

## 七、注意

- 不要手改 `.csproj`（Create Mod 生成的那份）。
- 修改 `.cs` 后必须重新 Build 才生效。
- 代码里的中文提示（如“祀岁翼 · 悬浮模式”）暂未本地化，后续统一处理。
