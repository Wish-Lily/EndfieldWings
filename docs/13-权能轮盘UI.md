# 13 · 权能轮盘 UI

> 2026-10-24 实现。佩戴祀岁翼时，屏幕右下角出现图标，点开后是十二权能轮盘。

![权能轮盘预览](assets/权能轮盘预览.png)

## 一、布局

- 轮盘中心：祀的身影（取自 `12岁图.jpg` 的中央裁切）
- 十二枚印记：从**右上 45°** 起，顺时针每 30° 一枚
- 顺序：**朔、望、令、均、颉、黍、绩、易、年、方、夕、余**
- 点击印记：开关该权能；开启时印记全亮，关闭时压暗

| 角度 | 印记 |
|---|---|
| -45°（右上） | 朔 |
| -15° | 望 |
| 15° | 令 |
| 45°（右下） | 均 |
| 75° | 颉 |
| 105° | 黍 |
| 135° | 绩 |
| 165° | 易 |
| 195°（左下） | 年 |
| 225° | 方 |
| 255° | 夕 |
| 285° | 余 |

## 二、交互

| 操作 | 效果 |
|---|---|
| 装备祀岁翼 | 右下角出现图标（带轻微脉冲） |
| 左键点图标 / **O 键** | 打开 / 关闭轮盘 |
| 左键点印记 | 开关对应权能 |
| **左键点中心祀像** | 开关「演化」（当前实现为完全无敌） |
| 鼠标悬停印记 | 放大 + 高亮，下方显示权能名与效果 |
| 点击轮盘外 | 关闭 |
| 右键 / Esc | 关闭轮盘 |
| 鼠标悬停 UI | 不会穿透到游戏世界（`mouseInterface`） |

> O 键是 tML 键位，可在「设置 → 按键 → 终末地 · 祀岁翼」里改。

## 三、状态存储

- `Common/Players/AuthorityPlayer.cs`
- 12 位按位存在 `Mask` 里，默认全开（`0xFFF`）
- `SaveData` / `LoadData` 写入角色存档，换世界保留
- 开启/关闭会影响权能实际效果（见 `docs/03`）

## 五、美术说明

- 背景：从 `12岁图.jpg` 裁中央 1000×1000 → 512×512，轻微模糊 + 压暗 34%，保留祀与墨迹
- 印记：程序生成，深色圆 + 楷体字（`STKAITI.TTF`），字直接烘焙进图片，运行时不依赖字体
- 想换图时：保持同名同尺寸覆盖即可，代码不用改

## 六、已知限制

- 没有快捷键，只能点右下角图标
- 半径固定 200px，低分辨率下可能偏大，后续按 `Main.UIScale` 缩放
- 开关状态目前**不影响任何数值**，等权能框架接上
- 多人下开关是本地状态，还没有同步
- 背景里保留了原图的少量文字（OPERATOR / UMB…），正式版建议换成无字版或重绘
