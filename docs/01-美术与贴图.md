# 01 · 美术与贴图

## 一、规格（硬性）

| 文件 | 规格 | 说明 |
|---|---|---|
| `Content/Items/Accessories/SiWings_Wings.png` | **86 × 248** | 4 帧**竖排**，每帧 86×62，透明背景 |
| `Content/Items/Accessories/SiWings.png` | 32 × 32 | 物品图标 |
| `icon.png` | 80 × 80 | 模组图标 |
| `icon_small.png` | 30 × 30 | 列表小图标（缺失也不影响） |

- 翅膀贴图里放的是**左右一对**，原版会按朝向镜像整张图。
- 左右两片必须**悬空分离**：中间约 12px 空隙，不接触身体。
- 长羽毛（羽翼）是翅膀的一部分，不能当拖尾裁掉。

## 二、参考素材（工作区根目录）

| 文件 | 内容 |
|---|---|
| `祀翅膀设定图.png` | 官方设定图截图，左半张 = 右翼，右半张 = 左翼 |
| `祀翅膀.png` | 游戏内实装截图，单侧水墨羽翼（灰底，需抠图） |

## 三、版本历史

| 版本 | 做法 | 结果 |
|---|---|---|
| v1 | 从设定图裁单侧、按墨色明度生成 alpha、镜像成对；后来做过一次左右半张平移对调 | 最像设定图，但 86px 下发糊 |
| v2_thin | 从 `祀翅膀.png` 抠出的羽翼按 5 层递减缩放/旋转 | 太细，像毛束 |
| v3_hybrid | v1 作底 + v2 的羽翼加粗叠在最上层 | 厚度够，但不算还原 |
| **v4（当前）** | v3 的基础上去掉旧的最上层（切 y<28），再叠实装羽翼 | 用户评价“更像自己做的，不过也很好看”，暂用 |

## 四、v4 的具体生成参数

1. 底图：`versions/SiWings_Wings_v1_2026-10-22.png`
2. 删除旧顶层：每帧把 `y < 28` 的 alpha 清零
3. 抠图（`祀翅膀.png`）：
   - 裁剪 `(18, 8, 350, 448)`
   - alpha = `(128 - 亮度) × 3.5`，低于 40 归零
   - 饱和度 > 42 的像素丢弃（去掉角色衣服的青色/金色）
   - 去掉左下角 `x < 85 且 y > 280`
   - 3px 中值滤波去背景细线
4. 叠层：缩放 0.18、旋转 33°、锚点 `(44, 26)`，同一片叠 4 次（偏移 (0,0)(1,0)(0,1)(1,1)）加粗
5. 4 帧：`0.80/5°`、`0.95/2°`、`1.00/0°`、`0.97/1°`，绕根部缩放旋转
6. 降采样 + `UnsharpMask(radius=1.1, percent=55, threshold=2)`

## 五、重新生成时注意

- 所有临时脚本已清理；参数都在上面，可照着重写一个 Python 脚本。
- **Pillow 直接保存的 PNG，tML 的图片加载器可能读不出来**（构建时报 `Image loading failed: unknown image type`，游戏里贴图会丢）。
  生成后必须用 GDI+ 重编码一遍：

```powershell
Add-Type -AssemblyName System.Drawing
$img = [System.Drawing.Bitmap]::FromFile($png)
$img.Save("$png.tmp.png", [System.Drawing.Imaging.ImageFormat]::Png)
$img.Dispose()
Move-Item "$png.tmp.png" $png -Force
```

- 构建时若出现一条 `WARN: Image loading failed`，通常来自 `icon_small.png`，官方 ExampleMod 也一样，可忽略。
- 换图后位置偏了：在 PNG 里平移内容（保留透明留白），**不要去改代码**。
