## 二、共同架构：门面 + 权威 + 表现

```
静态门面类（SeaDomain / Cyberspace / KikasaDomain）
   │  AltUse / Activate / Deactivate / Viewed
   ▼
每玩家权威状态（ModPlayer：CyberspacePlayer / KikasaDomainPlayer / HalibutPlayer 的域字段）
   │  层数、半径、中心、计时、同步
   ▼
领域载体（弹幕 SeaDomainProj : BaseHeldProj，或纯数据层 DomainLayer）
   │  每帧算距离、绑 NPC、施加效果
   ▼
表现层（Sky / Render / Fog / Shader / 音效），由「Viewed」决定画谁的域
```

关键点：**门面只做开关，真正的状态在 ModPlayer**，所以换武器/重连都不丢。

## 三、海领域（SeaDomain）

- `AltUse(player)` → `Activate` / `Deactivate`，带开关冷却 `ToggleCD`
- 开启时生成 `SeaDomainProj`，`ai[0]` = 层数（1..10）
- 弹幕内部维护 `List<DomainLayer>`：每层一个目标半径（`DomainLayer.LayerTargetRadius(i)`）
- 每帧：
  - 层数钳 1..10，初始化/扩展层
  - 半径内的 NPC 收进 `HashSet<int> boundNPCs`，按层施加压力（`PressurePerLayer = 20`）
  - 只在所有者端做权威判定
- `CanDamage() => false`：领域本身不造成伤害，只做范围效果

**可复用**：一个「不可伤害的常驻弹幕 + 分层半径 + HashSet 绑定」就是最朴素的领域。

## 四、赛博领域（Cyberspace）

- `BaseRadius = 600`，`MaxLayerCount = 3`
- 层半径倍率 `{1.0, 1.7, 2.6}`；层 RAM 消耗 `{0.4, 1.6, 6}/秒`
- 状态在 `CyberspacePlayer`：`DomainCenter`、`CurrentLayer`、每层 `layerExpand` / `layerBurstTimer`
- 中心有缓动（`DomainEaseTotal = 28` 帧），开关不是瞬移
- 有「Viewed」选择：自己的域优先，否则取范围内最近的他人域；客户端可设置不看他人域（`LegendDomainView.SpectateOthers`），但**功能仍然生效**
- 网络：`CWRNetChannel` + 二进制读写同步层数/中心

**可复用**：分层 + 半径倍率 + RAM 消耗 + 中心缓动，是「可成长的领域」模板。

## 五、血湖领域（KikasaDomain）与鬼梦

- `KikasaDomainPhase` 枚举：稳态 / 死寂等阶段，形态由 `KikasaDomainPlayer.IsRainForm` 区分
- 架构注释写得很清楚：「门面 + 观看选择，权威在 `KikasaDomainPlayer`」
- `KikasaDream` 是血湖之下更深一层：**每端从已同步的领域快照自算同一答案**（与湖面物理同款一致性模型），专用服务器不持有相位
- 也就是说：领域状态同步一次，视觉/判定由各端**确定性重算**，不逐帧发包

**可复用**：状态少、派生多时，用「同步快照 + 各端确定性重算」最省带宽。

## 六、领域冻结（CyberDomainFreeze）

- 条件：`CurrentLayer >= MaxLayerCount` 才能触发（满层处决）
- 流程：`TriggerFreeze` → 多人时发 `RamRequestToken` 请求 → 服务端 `ExecuteAuthoritativeFreeze` → 收集目标 → 冻结 NPC/弹幕 → `RamNet.SendStateSnapshot` 回发
- 冻结参数（时长、强度）按施术者领域强度取

**可复用**：领域大招 = 「满层 → 请求 → 服务端权威判定 → 快照回发 → 各端播放」。

## 七、如果我们要做翅膀领域 / Boss 领域

1. **翅膀领域**：可以做成一个大半径、不可伤害的常驻弹幕，跟随玩家；层数 = 演化层数；效果用 `ModPlayer` 的每帧距离判定，别用 `GlobalNPC` 全量扫描。
2. **Boss 领域**：Boss 自身当中心，`ModSystem` 或 `ModProjectile` 维护；进圈给 debuff、出圈移除；视觉用 `ModSceneEffect` / 天空替换。
3. **性能**：每帧只遍历一次 `Main.npc` / `Main.projectile`，用 `HashSet` 记录已绑定对象，避免重复施加减益。
4. **多人**：领域开关由所有者端决定并同步「层数 + 中心」，其余端重算；不要每帧同步目标列表。
5. **表现**：领域边界用 shader/圆环绘制；颜色/音效用武器主题（墨、海、赛博）。
