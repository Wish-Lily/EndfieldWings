# 11 · 岁时领域 · 负面效果草案

> 2026-10-23 草案，供参考，未实现。
> 定位：Boss 周围的负面领域，分两档——**岁时·岁兽残识**（弱）与**岁时·岁醒天时**（强）。
> 岁时语句的后半句「入时者……」就是这个领域对玩家的负面效果。

## 一、两档的区别

| | 岁兽残识 | 岁醒天时 |
|---|---|---|
| 半径 | 约 22 格 | 约 40 格 |
| 同时生效 | 1 个时辰 | 2 个时辰（当前 + 上一个残留） |
| 轮换 | 每 18 秒 | 每 12 秒 |
| 强度 | 单一弱化效果 | 主效果 + 追加效果，可叠 3 层 |
| 离开领域 | 3 秒后消失 | 立即消失，但 2 秒内回领域会续上 |
| 预警 | 边缘墨色变浓 | 边缘出现时辰字 + 音效 |

## 三、通用规则

1. **可读**：每个效果有图标、有文字提示、有领域边缘的时辰字。
2. **可解**：离开领域 3 秒解除；部分效果可被「逍遥」免疫（如果玩家有该权能）。
3. **不叠加同源**：同一时辰的残识与天时同时存在时，取强者，不叠两份。
4. **Boss 阶段**：残识 → 天时 是阶段推进，不是随机切换；天时的两个时辰按固定顺序轮换，方便玩家记。

## 三点五、亥食的计数口径（已确认）

- 计数 = **佩戴的「权能饰品」数量**（每枚刻印算 1 件），不是权能条数。
- **翅膀单独归为一类**（「祀岁翼」），不计入这个上限。
- 例：戴祀岁翼 + 2 枚刻印 → 计数 2；天时上限 3 → 不足，吃「饥饿」。
- 只戴祀岁翼（0 件刻印）→ 永远「不足」，这是当前设定的预期结果；
  以后刻印的弱化版权能做完，再看是否要给祀岁翼算 1 件。
- **残识**：只罚「不足」，超过上限不罚。
- **天时**：不足罚「饥饿」，超过罚「撑破」，两个是独立 debuff、图标不同。
- **祀岁翼的逍遥**可以真正免疫岁时（完整版），单独刻印的逍遥只能减半 —— 见 `docs/03` 强度层级。
- 建议给玩家一个 HUD：当前佩戴件数 / 上限，否则玩家不知道自己为什么被罚。

## 四、实现草案

```
Common/Shichen/Domain/
  ShichenDomainSystem.cs     ModSystem：Boss 战状态、当前时辰、半径、轮换计时
  ShichenDomainPlayer.cs     ModPlayer：进出领域检测、施加/移除 debuff
  ShichenDebuff.cs           12 个 ModBuff（或 1 个带类型的 Buff + 图标切换）
  ShichenDomainVisuals.cs    领域圆环 + 墨色渐变 + 时辰字
Boss/
  SuiBossAI.cs               阶段控制：残识 → 天时
```

- 领域检测：每帧算 `player.Distance(boss.Center)`，进/出时增删 buff，不要每帧重加。
- 范围效果：只对领域内玩家生效；多人下由服务端判定，客户端只做表现。
- 视觉：`ModSceneEffect` 或 `ModSystem.PostDrawTiles` 画圆环；时辰字用 `Main.fontMouseText`。
- 数值全部走 `ModBuff` + `ModPlayer` 的修正，方便后续调平衡。
