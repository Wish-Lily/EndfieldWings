# 02 · 飞行系统

## 一、模式

| 模式 | 名称 | 逻辑 |
|---|---|---|
| 0 | 巡航 | 完全交给原版翅膀逻辑；本 mod 只负责无限飞行 + 切换 |
| 1 | 悬浮 | 自定义控制器接管速度：松手即停、方向键即时变向 |

切换：**空中**快速点两下跳跃，窗口 15 帧；地面连跳不会误触。

## 二、代码位置

```
Common/Players/SiWingsPlayer.cs   ← 飞行控制器
Content/Items/Accessories/SiWings.cs ← 翅膀数值、加成、配方
```

关键实现点：

- 物理写在 `ModPlayer.PreUpdateMovement()`：它在“按速度移动位置”之前执行，改完当帧生效，不会被原版重力/翅膀逻辑覆盖。
- 不能靠 `velocity.Y == 0` 判断落地：重力和碰撞的先后顺序会让站地上的玩家在 `PreUpdateMovement` 阶段仍带向下速度。**改用查脚下一格物块**（`IsStanding`，含平台）。
- 只驱动 `Main.myPlayer`，避免多人下改写其他玩家速度。

## 三、当前数值（`SiWings.cs`）

```csharp
new WingStats(
    flyTime: 60 * 60,              // 3600，每帧补满 = 无限飞
    flySpeedOverride: 16f,         // 82 mph
    accelerationMultiplier: 16f,   // 星盘倍率
    hasHoldDownHoverFeatures: true,
    hoverFlySpeedOverride: 8f,     // 41 mph
    hoverAccelerationMultiplier: 4.5f);

// VerticalWingSpeeds
ascentWhenFalling = 0.85f;   // 下落缓冲（原值）
ascentWhenRising = 0.15f;
maxCanAscendMultiplier = 1f;
maxAscentMultiplier = 4.5f;  // 星盘
constantAscend = 0.135f;     // 上升加速度（原值）
```

模式二参数（`SiWingsPlayer.cs`）：

| 常量 | 值 |
|---|---|
| `HoverAscendSpeed` | 6.5 |
| `HoverDescendSpeed` | 6.5 |
| `HoverHorizontalSpeed` | 8 |
| `DoubleTapWindow` | 15 帧 |

数值来源：中文 Terraria Wiki「天界星盘」与「翅膀」页面。
**注意**：用户明确要求「上升加速度 / 下落缓冲 / 飞行时长」保持原值，不要再改成星盘的 0.1 / 0.95 / 180。
